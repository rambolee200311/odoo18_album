## 1. 登记规则

本文件只登记已经观察到、但当前实现没有完全达到目标或仍需上游决策的技术债。

每条技术债必须说明：

- 当前现状；
- 目标状态；
- 影响范围；
- 解决责任和最晚处理节点；
- 验收或关闭条件。

技术债不得被默认为已解决，也不得通过 UI 隐藏或文档描述替代实现修复。
技术债的关闭必须伴随明确的验证证据（浏览器验证、自动化测试或人工步骤记录），不能仅凭“看起来已修复”关闭。
本登记册冻结后，新增、拆分、合并或关闭技术债必须通过版本化变更记录，并经过项目审批；冻结不代表登记项已经关闭。

## 2. 技术债清单

### TD-001 — Source Config 字段选择器

| 项目 | 内容 |
|---|---|
| 状态 | Open |
| 严重度 | Medium |
| 来源 | CC-01 HVR-SCN-005、HVR-EVD-009 |
| 当前现状 | Source Config 的 `field_name` 使用文本输入，用户需要手工填写字段名。 |
| 目标状态 | 在选定 `model_id` 后，界面提供符合约束的候选字段选择。候选字段发现是从 `ir.model.fields` 查询 `ttype="many2many"` 且 `relation="ir.attachment"` 的字段，作为可选候选；候选字段暴露则要求管理员显式保存并启用 Source Config，候选列表不会自动成为合法来源。 |
| 影响范围 | CC-01 后台配置体验；Source Config 配置错误的人工输入风险。 |
| 业务影响 | 配置人员可能输入拼写错误或不存在的字段名；保存/启用时的服务端校验仍提供最终保护。 |
| 安全影响 | 候选字段展示必须继续遵守显式配置原则，不能因为增加下拉选择而自动暴露所有候选来源。 |
| 责任范围 | 由 CC-01 修复。 |
| 责任理由 | TD-001 直接属于 CC-01-T05 Source Config ORM 模型和 CC-01-T07 后台配置视图；在 CC-01 关闭前修复可避免文本输入错误外溢到 CC-02。 |
| 最晚处理节点 | CC-01 关闭前。 |
| 关闭条件 | `field_name` 可基于 `model_id` 选择合法候选字段；非法字段不会出现在候选项中；保存和启用校验仍有效；对应浏览器验证证据写入 HVR。 |
| 追溯 | TDD §2.5；CC-01 §3.4、§5.5、AC-08；HVR-SCN-005、HVR-EVD-009 |

### TD-002 — Item 附件预览和删除 Widget

| 项目 | 内容 |
|---|---|
| 状态 | Open |
| 严重度 | Medium |
| 来源 | CC-02 HVR-SCN-005；CC-02 用户反馈 |
| 当前现状 | Item 当前使用 Odoo 标准附件/Many2many 界面，能够完成上传和删除后的业务关系处理，但缺少面向媒体的缩略图预览、媒体查看和直观删除交互。 |
| 目标状态 | 为 Item 附件字段提供媒体 Gallery Widget：显示图片缩略图或视频文件入口；支持点击预览；支持在可编辑状态下删除附件关系；删除关系不误删仍被其他业务使用的 `ir.attachment`。 |
| 参考实现 | [photo_gallery_field.js](../../mymodules/wd_qooling_app/static/src/js/photo_gallery_field.js) 的预览、文件元数据加载、删除关系和失败通知交互；该文件仅作为设计参考，不得让 `wd_evidence_album` 依赖 `wd_qooling_app`。 |
| 影响范围 | CC-02 Item 浏览和维护体验；媒体验收效率。 |
| 业务影响 | 用户需要通过标准表单和附件字段识别媒体，预览和删除操作不够直观；不影响当前媒体校验、Item 创建和附件生命周期规则。 |
| 安全影响 | Widget 必须继续遵守 Odoo 权限；预览不得绕过附件访问控制；删除只能删除 Item 与附件的关系，不能默认删除共享附件。 |
| 责任范围 | 由后续 CC（待编号）处理；不回写 CC-02 已通过的媒体采集契约。 |
| 最晚处理节点 | CC-03 开始前确认是否纳入；若不纳入，需在对应 FR 中保留为 Open 技术债。 |
| 关闭条件 | Item 附件支持图片/视频预览；可编辑状态下可删除关系；预览和删除遵守权限；删除 Item 或关系不误删共享附件；浏览器验证和回归证据写入对应 HVR。 |
| 追溯 | CC-02 §7.2、AC-06、AC-07；CC-02 HVR-SCN-005；参考实现 `photo_gallery_field.js` |

## 4. TD-001 关闭后的回归范围

TD-001 关闭后必须回归以下内容：

- Source Config 保存校验仍然有效；
- 停用/启用逻辑不受影响；
- 已存在配置不因 UI 变化被破坏；
- CC-02 的字段校验调用不受影响；
- 候选字段列表不会绕过显式启用而自动成为合法来源。

## 4.1 TD-002 关闭后的回归范围

TD-002 关闭后必须回归以下内容：

- 图片和视频仍通过统一媒体校验；
- 预览遵守附件访问权限；
- 删除 Item 或附件关系不会误删共享附件；
- 删除附件后 Item 可用性状态仍按 CC-01 生命周期规则刷新；
- 直接上传和来源型 Item 的来源追溯字段不受影响。
